# 使用說明

這個資料夾是獨立版本，不依賴原網站。個人背包只寫入此瀏覽器的 localStorage，換裝置前請匯出 JSON。

首次開啟載入的是 GitHub `fudiyangjin/StarResonanceAutoMod` 的 `modules.vdata` 公開資料快照，共 1,371 件（攻擊 1,174、守護 75、輔助 122）。這是公開快照，不代表即時玩家背包；截圖中的玩家背包數量可因帳號與時間不同而不同。

匯入格式：

```json
{
  "version": 1,
  "modules": [
    {
      "id": "support-001",
      "name": "我的輔助模組",
      "type": "輔助",
      "stats": { "特攻治療加持": 8, "攻速專注": 5 }
    }
  ]
}
```

計算會在符合門檻的同類型模組中，搜尋五件不同 ID 的組合。分數為勾選詞條的五件合計乘上權重之總和；最低需求也是五件合計。搜尋到達節點上限時會標示暫定結果，不保證是全域最佳。

工具容量限制是 2 MiB、2,000 件模組、64 種詞條、每件 1–12 個詞條，詞條數值為 1–1000 的整數。這些是輸入限制，不是遊戲規則。
